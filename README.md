# 100on100 releases

Compiled releases of the **100on100 decoder**: lossless imaging with a decoder small enough to
audit.

**No release has been published yet.** The first release will appear under
[Releases](https://github.com/100on100/releases/releases) once its verification gates pass.

Each release will contain:
- the decoder for Linux (x86-64, ARM64), macOS (Apple silicon) and WebAssembly, as a command-line
  tool and a library, with its C header;
- `SHA256SUMS` for every file;
- `PROVENANCE.txt`, which records how each file was built;
- the licence and third-party notices.

**Licence:** the binaries are free for evaluation, and production use requires a commercial
licence. The full licence terms will ship with the first release. Source code is not distributed.
